# زاد المسلم — بناء APK على GitHub

## التشغيل
1. ارفع الملفات إلى المستودع (استبدل القديم).
2. افتح تبويب **Actions** ← **Build APK** ← **Run workflow**، وانتظر 6–10 دقائق.
3. من صفحة التشغيلة المكتملة، قسم **Artifacts** في الأسفل: نزّل `zad-almuslim-apk` وثبّت `app-debug.apk`.

## ما الذي تغيّر
- إشعار التشغيل الصوتي في ستارة الهاتف وشاشة القفل (تشغيل/إيقاف/السابق/التالي).
- الموقع: عبر إضافة Capacitor Geolocation (تطلب الإذن من نظام أندرويد مباشرة).
- التنبيهات: تُجدوَل داخل النظام وتصل والتطبيق مغلقًا، بصوت العصافير للصباح والمساء وتلاوة الآية للصلاة على النبي ﷺ.
- المصحف: ورق كريمي مضيء (#fff9f1) وحبر أسود وزخارف بنية مثل تطبيق آية.
- توقيع ثابت (`zad-debug.keystore`): التحديثات القادمة تُثبَّت فوق القديم دون حذف البيانات.

## ملاحظات
- أول تثبيت لهذه النسخة يحتاج حذف النسخة القديمة (توقيعها مختلف). بعدها تُحدَّث مباشرة.
- بعد التثبيت: اسمح بالإشعارات والموقع، واسمح بـ«التنبيهات الدقيقة»، وفي إعدادات البطارية اجعل التطبيق «غير مقيَّد».
- ملفا `zad-native.js` و`zad-geo.js` صارا داخل `index.html`؛ احذفهما من المستودع، وكذلك المجلد `github` (بدون نقطة).
- لا تعدّل `index.html` من محرر GitHub في الهاتف؛ ارفعه بدل القديم.

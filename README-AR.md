# إصلاح زاد المسلم (أندرويد)

التشخيص: الـAPK يحوي إضافة StatusBar فقط، والتطبيق يعتمد على Notification وnavigator.geolocation وmediaSession الخاصة بالمتصفح، وWebView لا يحوّلها إلى إشعارات/إذن موقع/مشغّل في الستارة.

## التركيب
1. انسخ مجلد zad-native-patch إلى جذر المشروع (بجانب package.json) وارفعه إلى GitHub.
2. في ملف workflow أضف قبل خطوة بناء gradle (وبعد npm ci):
   `- run: bash zad-native-patch/apply-patch.sh`
3. ابنِ الـAPK، ثبّته، وافتح التطبيق، واسمح بالإشعارات والموقع و«المنبّهات والتذكيرات».

## ما يفعله
- الموقع: إذن حقيقي + تحديد تلقائي أول تشغيل + أقرب مدينة (حتى 60 كم) مع بقاء الإحداثيات الدقيقة.
- الإشعارات: جدولة أصلية 7 أيام (الأذكار، الصلاة على النبي، الجمعة/الاثنين/الخميس، تنبيهات الصلاة، التنبيهات المخصصة)، تعمل والتطبيق مغلق وتُستعاد بعد إعادة التشغيل، تُجدَّل تلقائيًا عند فتح التطبيق أو تغيير الإعدادات/الموقع. الضغط على الإشعار يفتح القسم.
- الستارة: إشعار وسائط حقيقي (تشغيل/إيقاف/السابق/التالي/تقدّم) لتلاوة القرآن والأذكار، وخدمة مقدّمة تُبقي الصوت يعمل في الخلفية.

## غير مشمول بعد
ختمة القرآن ومواسم العبادات وصوت الأذان نفسه والتطبيق مغلق (يحتاج تشغيلًا أصليًا للصوت).
## بعد التثبيت
على بعض الأجهزة (شاومي/سامسونج/أوبو) عطّل «توفير البطارية» للتطبيق.
